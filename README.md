# Animal-Vet-App
This App will provide information on select animals and include images and details regarding the habbit of each, it will also provide a map provide the location of nearby vets and allow users to gather information regarding that specific vet clinic.

The Vet map lets you manually save named vet locations: tap the map to add a pin,
and tap a pin to edit its position or remove it. The location picker opens at the
pin's saved position. Pins are stored on the device. Map tiles require an
internet connection and are provided by OpenStreetMap; the app does not
automatically discover nearby vets.
Saved vets use green cross pins, while the location being edited uses a blue
target pin and shows the vet's name in the picker.
